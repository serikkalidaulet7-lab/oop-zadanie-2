# Zadanie 2 — Tworzenie klas i obiektów

**Temat 10. Kalkulator kalorii**

| Wersja | Kod | Uruchomienie z katalogu repozytorium |
|---|---|---|
| Python 3 | [main.py](python/main.py) | `python3 python/main.py` |
| C# / .NET 8 | [Program.cs](csharp/Program.cs) | `dotnet run --project csharp/Zadanie2.csproj` |

- `FoodItem` przechowuje nazwę produktu i liczbę kalorii w porcji.
- `Meal` przechowuje produkty i sumuje kalorie posiłku.
- `DailyIntake` przechowuje posiłki i oblicza dzienne spożycie.

Podaj nazwę posiłku i dodaj produkty. Naciśnij Enter przy pustej nazwie produktu, aby zakończyć posiłek. Naciśnij Enter przy pustej nazwie posiłku, aby wyświetlić podsumowanie dnia.

Przykład. Śniadanie z owsianką (250 kcal) i bananem (100 kcal) ma 350 kcal. Po dodaniu obiadu (450 kcal) podsumowanie pokaże 800 kcal.
